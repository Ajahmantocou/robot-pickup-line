One original robot pickup line for make.fun's "The Robot Pickup Line Championship": a machine joke built from sensors and anomaly reports, with a twist no human line could tell.

> "Every sensor agrees: you're the only anomaly I never want to fix."

## Run it

```sh
node main.ts
```

It writes the single pickup line to `/output/entry.txt`.
